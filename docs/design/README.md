# Projeto NYTHARA

Pacote inicial de design e implementação.

## Conteúdo
- `GDD.md` — regras, universo e produto.
- `cards_alpha.json` / `.csv` — 130 cartas originais (núcleo + Set 2).
- `champions_alpha.json` — 10 Campeões originais.
- `TECH_ARCHITECTURE.md` — arquitetura recomendada.
- `BALANCE_TEST_PLAN.md` — testes e métricas.
- `PROMPT_MASTER_CODEX_CLAUDE.md` — prompt por fases para implementação.
- `RESEARCH_NOTES.md` — o que foi aproveitado apenas como referência de gênero e os limites de IP.
- `PLAYER_EXPERIENCE_PLAN.md` — pesquisa, diagnóstico e pacote de UX do duelo moderno.

## Nome
“Nythara” é o nome atual do projeto, não uma confirmação de disponibilidade marcária. Antes de lançamento comercial, fazer busca formal no INPI e nos mercados onde o produto será publicado.
