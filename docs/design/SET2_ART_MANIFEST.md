# Set 2 — Manifesto de Arte (VR-081..VR-130)

Mesmo modelo do Set 1: pintura digital dark-fantasy do universo Nythara,
retrato vertical 640×960, sem texto/moldura/logotipo na imagem, foco único
central, iluminação dramática do Eclipse. Salvar como
`web/public/card-art/vr-0NN.webp` (minúsculas). Até lá, o fallback
procedural (CardSigil) cobre as cartas sem arte.
